# OSNotes - Desktop iOS-style Notes App

Настольное приложение для заметок в премиальном стиле iOS с поддержкой сквозного (E2EE) шифрования и бесшовной облачной синхронизации через GitHub.

## Особенности

- **[E2EE Шифрование]**: Все заметки шифруются локально алгоритмом AES-256 GCM. Мастер-пароль не хранится на диске, проверка осуществляется через хэш-верификатор. Защита включается и отключается по желанию пользователя в настройках.
- **[Гибридный Sync]**: Бесшовная синхронизация с приватным репозиторием `ios-notes-data` на вашем GitHub. Поддерживается как автоматический вход в один клик через GitHub OAuth, так и ручное подключение по Personal Access Token (PAT). Приложение само создает репозиторий и бережно мержит локальные заметки с облаком без потерь.
- **[Гибкая Кастомизация]**: Настройка темы (Светлая / Темная / Системная), выбор фирменного акцентного цвета приложения, управление размером шрифта в редакторе и сортировка списка заметок.

## Требования

Для разработки и сборки приложения вам понадобятся:

- Go (1.23+)
- Node.js (v18+) и npm
- Wails CLI

Установка Wails CLI:

```bash
go install github.com/wailsapp/wails/v2/cmd/wails@latest
```

## Запуск в режиме разработки

Для запуска приложения с горячей перезагрузкой выполните:

```bash
wails dev
```

## Сборка EXE (для Windows)

Для компиляции готового исполняемого файла выполните:

```bash
wails build
```

После завершения сборки исполняемый файл будет доступен по пути:

```
build/bin/OSNotes.exe
```
